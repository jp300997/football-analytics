# Football analytics portfolio

Jun Park's independent football analytics work, published as a static site.

- `index.html` - overview of the three projects
- `tactics-board.html` - EPL Tactics Board, all 20 Premier League clubs, 2025/26 event data
- `opposition-board.html` - automated opposition dossiers for 51 EPL and Champions League clubs

Everything is a self-contained HTML file with no server or build step. Aggregated statistics only; no raw event data is redistributed.
